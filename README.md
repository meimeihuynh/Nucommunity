## Features
----
- **Home / General Community page** with its own set of discussion categories
- **Character pages** built from one reusable template and themed per character
- **Shared discussion components** (category navigation, category sections, discussion feed) used across both page types
- **Data-driven categories and characters**, so adding a character or category means editing data, not writing a new page

- React (JavaScript)
- Next.js
